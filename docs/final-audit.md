## 재현·보관 상태

- `npm run check`: 단위·HTTP 10개, 형 검사·클라이언트/서버 빌드 통과.
- `npm run test:production`: 컴파일된 운영 진입점·정적 자산·CSP·보안 쿠키·관리 CLI 스모크 통과.
- `PLAYWRIGHT_CHANNEL=chrome npm run test:e2e`: 3개 시나리오 통과. API·WebAuthn·UX와 실제 서명 검증을 포함.
- 두 운영 검증 스크립트의 생성 계정은 모두 정리했습니다. 소유자 계정·키·자료는 유지했습니다.
- 공개 증거에서 초기 링크·쿠키·토큰·개인키·실제 DB 연결값을 제외합니다. 환경변수와 실제 DB는 Git/배포 입력에서 제외합니다.
