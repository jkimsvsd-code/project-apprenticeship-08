# UX 체크리스트

상태: U1–U6을 구현하고 Chromium 가상 인증기·axe·320/375px 화면에서 자동 검증했습니다. 실제 기기·다른 브라우저·스크린리더 수동 확인은 별도 필요합니다.

## 과제 필수 UX

- [x] 공개 소개와 잠긴 공간의 경계가 명확하다.
- [x] 패스키마다 이름과 등록일을 표시한다.
- [x] 등록 취소 시 안내하고 등록을 확정하지 않는다.
- [x] 비밀번호 입력란이 없다. 운영체제의 기기 잠금 해제 UI와 서비스 비밀번호를 구분해 설명한다.
- [x] 패스키가 없거나 모두 사용할 수 없을 때의 동작과 한계를 안내한다.
- [x] 공개 첫 화면과 제출 기록 확인에 가입·로그인을 요구하지 않는다.

## U1 · 사용 전 환경 안내

- [x] HTTPS/localhost와 WebAuthn 지원 여부를 확인한다.
- [x] 지원 여부를 실제 로그인 성공 보장으로 표현하지 않는다.
- [x] 사용할 수 없는 환경에는 이유와 지원 브라우저·다른 기기 사용 등 다음 행동을 안내한다.

구현 위치: `src/client/shared/`, `src/client/passkeys/`.

## U2 · 진행 상태와 재시도

- [x] 준비·기기 확인 중·성공·취소·시간 초과·실패를 구분한다.
- [x] 처리 중 중복 요청을 막고, 종료 후 재시도할 수 있다.
- [x] 재시도는 서버에서 새 질문을 발급받는다.
- [x] 오류 문구가 다음 행동을 안내하고 서버 내부·타 계정 정보를 노출하지 않는다.

구현 위치: `src/client/shared/`, `src/client/passkeys/`, `src/server/auth/`.

## U3 · 원래 목적지 복귀

- [x] 비공개 공간에서 시작한 로그인은 성공 후 해당 위치로 돌아온다.
- [x] 복귀 주소는 허용한 내부 경로만 사용하고 외부 URL은 거절한다.
- [x] 취소·실패 시 자료를 노출하지 않고 재시도 동선을 유지한다.

구현 위치: `src/client/shared/`, `src/client/private-space/`, `src/client/passkeys/`.

## U4 · 예비 패스키 등록 유도

- [x] 패스키가 하나뿐이면 분실 대비 이유와 추가 등록 버튼을 제공한다.
- [x] 두 번째 등록 후 목록·개수를 갱신한다.
- [x] 같은 패스키의 동기화와 별도 credential 등록을 구분해 안내한다.
- [x] 저장소 메모를 접힌 선택 항목으로 표시하고, 실제 저장소 선택은 브라우저·기기 인증 창에서 한다고 안내한다.
- [x] 등록 목록의 저장소 정보는 사용자 메모임을 표시하며 확인되지 않은 값은 확인 불가로 표시한다.
- [x] 두 번째 키 등록 3단계, QR 경로, 동기화된 기존 키의 중복, 원하는 저장소가 없을 때의 다음 행동을 안내한다.
- [x] 메모를 바꿔도 기존 인증기의 중복 등록은 거절되고 별도 인증기로는 등록되는 것을 실제 CDP WebAuthn으로 검증한다.

구현 위치: `src/client/passkeys/`.

## U5 · 삭제 확인과 영향 안내

- [x] 삭제할 이름과 삭제 후 남는 개수를 표시한다.
- [x] 확인·취소를 제공하고, 마지막 패스키는 삭제하지 못하도록 안내한다.
- [x] 서버에서도 본인 소유권과 마지막 패스키 정책을 검사한다.
- [x] 서비스에서 삭제한 뒤에도 기기·제공자의 저장 항목이 남을 수 있음을 안내한다.

구현 위치: `src/client/passkeys/`, `src/server/auth/`, `src/server/authorization/`.

## U6 · 모바일·키보드 접근성

- [x] 작은 화면에서도 가로 넘침 없이 내용·주요 버튼을 사용할 수 있다.
- [x] 주요 조작의 터치 영역을 충분히 확보한다.
- [x] 모든 앱 내 조작을 키보드로 수행하고 포커스를 확인할 수 있다.
- [x] 대화상자의 포커스 이동·복귀와 취소 동작이 일관적이다.
- [x] 입력 이름·오류·진행 상태가 보조기술에 전달되고 색만으로 상태를 구별하지 않는다.

구현 위치: `src/client/shared/`, `src/client/` 전체. 검증 증거: `evidence/ux/`.

자동 증거: evidence/ux/verified-ux.json. 작은 화면은 데스크톱 브라우저의 viewport 검사이며 모바일 실기기 검증을 대신하지 않습니다.

저장소 메모 회귀 증거: [자동 결과](../evidence/ux/verified-storage-memo.json), [데스크톱](../evidence/ux/storage-memo-desktop.png), [모바일](../evidence/ux/storage-memo-mobile.png). 실제 제공자 저장 위치를 검증한 결과가 아닙니다.
