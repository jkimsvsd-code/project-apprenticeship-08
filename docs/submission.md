## 짧은 확인 방법 · 4줄

어디로 가나요: https://project-apprenticeship-08.vercel.app (소스는 위 GitHub URL).
세 단계 안에 무엇을 하나요: 공개 소개 열기 → 관리자 전용 검토 버튼의 로그인 안내 확인 → 소스의 인증 설명서에서 성공·거절 기록 확인.
무엇이 보이면 통과인가요: 기존 J 소개는 인증 없이 보이고 비공개 내용은 감춰지며, 필수 4가지 검증의 요청·응답 기록이 있음. 실제 HTTPS 운영은 검증했고 물리 기기는 별도 확인 필요.
안 될 때는 무엇이 보이나요: 미지원·취소·시간 초과·연결 실패 안내와 재시도 동선. API는 미인증 401·타인 자료 403·잘못된 인증 400을 반환.

AI에게 맡긴 일: 기술 스택 선정 근거, 공개 소개 보존, 패스키·세션·자료 격리·U1–U6 구현과 자동 검증·문서 정리.
내가 직접 판단한 일: 필수 요구사항·U1–U6 및 기본 정책 승인, 과제1 원본 저장소 지정. 추가 판단은 사용자 최종 보완 필요.
AI 제안을 따르지 않은 일: 사용자 작성 필요. 없다면 그 이유도 확인해 작성.
